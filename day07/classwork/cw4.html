Python

Python არის მარტივად წასაკითხი და მრავალმხრივი პროგრამირების ენა, რომელიც ფართოდ გამოიყენება ხელოვნურ ინტელექტში, მონაცემთა ანალიზსა და ვებ-დეველოპმენტში.

JavaScript

JavaScript ვებგვერდების მთავარი ენაა, რომელიც საიტებს ინტერაქტიულსა და დინამიკურს ხდის — ამუშავებს ღილაკებს, ანიმაციებსა და მონაცემთა განახლებას.

JavaScript

JavaScript ვებგვერდების მთავარი ენაა, რომელიც საიტებს ინტერაქტიულსა და დინამიკურს ხდის — მაგალითად, ამუშავებს ღილაკებს, ანიმაციებსა და მონაცემთა განახლებას.

C++

C++ არის მაღალი წარმადობის მქონე პროგრამირების ენა, რომელსაც ძირითადად იყენებენ ვიდეოთამაშების, ოპერაციული სისტემებისა და რთული პროგრამების შესაქმნელად.

CSS-ის სამყარო

CSS (Cascading Style Sheets) არის სტილიზაციის ენა, რომელიც HTML ელემენტებს ვიზუალურ სახეს აძლევს — აკონტროლებს ფერებს, ფონტებს, ზომებსა და განლაგებას ეკრანზე.
